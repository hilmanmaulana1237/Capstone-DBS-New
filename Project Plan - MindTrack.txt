A.	Ringkasan Eksekutif
Latar Belakang
Di era modern yang serba cepat ini, mahasiswa dan pekerja muda menghadapi tuntutan akademik serta profesional yang semakin berat. Menurut data WHO (2022), lebih dari 280 juta orang di dunia mengalami depresi, dan Indonesia menempati peringkat ke-5 negara dengan tingkat stres kerja tertinggi di Asia Tenggara. Riset Riskesdas 2018 menunjukkan prevalensi gangguan mental emosional pada penduduk usia ≥15 tahun mencapai 9,8%, meningkat dari 6% di tahun 2013. Ironisnya, sebagian besar individu baru menyadari gejala gangguan kesehatan mental setelah kondisinya memburuk — padahal deteksi dini melalui analisis pola gaya hidup (durasi tidur, tingkat stres, aktivitas fisik, detak jantung) dapat menjadi langkah preventif yang efektif. Selain itu, gangguan tidur seperti Insomnia dan Sleep Apnea memiliki korelasi kuat dengan penurunan produktivitas dan kualitas hidup, namun jarang terdeteksi tanpa pemeriksaan klinis yang mahal.

Problem Statement
Bagaimana membangun platform web cerdas berbasis AI yang mampu menganalisis data gaya hidup harian pengguna (durasi tidur, aktivitas fisik, detak jantung, tingkat stres, jumlah langkah harian) secara otomatis, memprediksi risiko gangguan tidur (Normal, Insomnia, Sleep Apnea) dengan model Deep Learning, serta menyajikan dashboard analitik interaktif untuk memahami tren dan korelasi faktor-faktor kesehatan mental di tingkat populasi?


Research Questions
•	Faktor gaya hidup apa saja yang secara signifikan berkontribusi terhadap risiko gangguan tidur dan burnout?
•	Bagaimana pola korelasi antara durasi tidur, aktivitas fisik, detak jantung, dan tingkat stres terhadap jenis gangguan tidur?
•	Bagaimana mensegmentasi populasi pengguna berdasarkan profil risiko kesehatan mental untuk memberikan rekomendasi personal?
•	Seberapa akurat model Deep Learning dengan Custom Attention Layer dalam mengklasifikasikan gangguan tidur berdasarkan data gaya hidup?

Mengapa Tim Ini Memilih Proyek Ini
 
Beberapa anggota tim pernah mengalami langsung dampak burnout dan gangguan tidur selama masa perkuliahan maupun saat mengerjakan proyek intensif. Pengalaman ini membuka kesadaran bahwa deteksi dini sangat diperlukan, namun akses ke layanan kesehatan mental masih terbatas — baik dari sisi biaya maupun stigma sosial. MindTrack hadir sebagai solusi preventif yang bersifat non-invasif dan mudah diakses: cukup dengan mengisi form gaya hidup harian, pengguna dapat mengetahui tingkat risiko gangguan tidurnya secara instan. Tantangan ini juga selaras dengan komposisi tim: model prediksi membutuhkan AI Engineer, analisis dan visualisasi data membutuhkan Data Scientist, dan penyajian antarmuka web yang responsif beserta backend yang aman membutuhkan Fullstack Developer — ketiganya berkontribusi setara dan bermakna.

Kriteria Penilaian	Penjelasan
Inovasi	Ide proyek ini tergolong sangat inovatif karena menghadirkan pendekatan preventif berbasis "lifestyle data" (non-invasif) untuk mendeteksi risiko kondisi kesehatan mental yang umumnya diabaikan hingga parah, membantu para user maupun instansi korporat mendeteksi tingkat kelelahan pekerjanya lebih mudah. Penerapan Custom Attention Layer pada algoritma Deep Learning juga meningkatkan kemampuannya memahami fitur gaya hidup yang paling berisiko secara spesifik. Selain memberikan layanan perseorangan lewat aplikasi web cerdas, proyek ini juga menyediakan Streamlit dashboard yang menyuguhkan gambaran analitik holistik bagi pemangku kepentingan.
Kemungkinan Realisasi	Gagasan MindTrack memiliki kapabilitas dan kemungkinan besar untuk direalisasikan tepat waktu. Penggunaan sumber daya berupa dataset open-source dari Kaggle sangat mempercepat proses tanpa memerlukan komplikasi birokrasi ekstraksi rekaman medis primer. Struktur Microservices yang digunakan (Vite+React, Express.js, FastAPI, dan Streamlit) terbukti kokoh dan memungkinkan setiap Learning Path bekerja independen maupun komplementer dalam timeline 5 minggu. Perpaduan stack teknologi yang solid (di-deploy via layanan seperti Vercel dan Render) menjamin implementasinya menjadi MVP yang teruji dengan sempurna sesuai standar kelayakan.
 
B.	Cakupan Proyek dan Hasil Kerja
Ruang Lingkup Proyek
Proyek MindTrack mencakup pengembangan platform web full-stack yang terintegrasi dengan pipeline data science dan model AI Deep Learning. Berikut adalah cakupan teknis per learning path:

Fullstack (Anggota 1 & Anggota 2):
•	Membangun RESTful API menggunakan Express.js (Node.js) sesuai standar konvensi RESTful
•	Mengintegrasikan networking calls menggunakan Fetch API untuk berinteraksi dengan API model AI (FastAPI)
•	Menggunakan module bundler Vite untuk membangun project aplikasi web
•	Membangun layout aplikasi web responsif dengan React.js (tanpa web generator) didukung framework Tailwind CSS
•	Mengintegrasikan fitur AI/ML pada front-end secara langsung melalui proxy ke backend
•	Deployment aplikasi web ke server menggunakan Vercel (FE) dan Render.com (BE)
•	RESTful API menyimpan data menggunakan database SQLite (file persisten mindtrack.db)
•	Implementasi autentikasi pengguna menggunakan JWT (JSON Web Token) dan Bcrypt untuk hashing password
•	Implementasi Rate Limiter untuk keamanan endpoint AI dari DDoS/Spam Request
•	[Opsional] Membuat mockup UI menggunakan Figma sebagai representasi visual desain antarmuka

Data Science (Anggota 3 & Anggota 4):
•	Mengumpulkan dan menganalisis dataset Sleep Health and Lifestyle dari Kaggle (374 responden, 13+ kolom)
•	Melakukan proses Data Wrangling end-to-end: gathering, assessing, cleaning
•	Mendefinisikan pertanyaan bisnis yang dapat diukur dari data kesehatan dan gaya hidup
•	Melakukan Exploratory Data Analysis (EDA) untuk insight korelasi faktor gaya hidup terhadap gangguan tidur
•	Membuat visualisasi data dan explanatory analysis untuk menjawab pertanyaan bisnis
•	Membangun dashboard interaktif menggunakan Streamlit untuk menampilkan insight, evaluasi model AI, dan prediksi mandiri
•	Memastikan data siap diproses oleh model AI (feature engineering & Data Dictionary)
•	[Opsional] Melakukan feature engineering untuk menghasilkan fitur yang lebih informatif (Systolic BP extraction, BMI mapping)
•	[Opsional] Deployment dashboard Streamlit ke Streamlit Community Cloud
•	[Opsional] Membuat laporan teknis komprehensif dari Problem Discovery hingga hasil akhir (PDF)

AI Engineer (Anggota 5):
•	Membangun model Deep Learning menggunakan TensorFlow Functional API: Model klasifikasi multi-class gangguan tidur (Normal, Insomnia, Sleep Apnea) berbasis data gaya hidup pengguna untuk mendukung deteksi dini kesehatan mental
•	Mengimplementasikan Custom Attention Layer (tf.keras.layers.Layer) untuk memberikan bobot lebih pada fitur paling relevan dalam prediksi
•	Mengimplementasikan Custom Callback (AccuracyThresholdCallback) untuk menghentikan training otomatis saat val_accuracy ≥ 85%
•	Menyimpan dan mengekspor model yang telah dilatih dalam format TensorFlow (.keras)
•	Membuat kode sederhana untuk proses inference model dan scaling input
•	[Opsional] Mengembangkan REST API mandiri menggunakan FastAPI untuk melayani model ML
•	[Opsional] Mengimplementasikan Feature Importance via Permutation untuk interpretasi model
•	[Opsional] Memastikan model memiliki performa baik: Akurasi minimal 85%
