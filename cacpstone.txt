Tentang Capstone Project
Capstone Project merupakan tahap akhir dari seluruh rangkaian kegiatan belajar di Program Coding Camp powered by DBS Foundation yang dirancang sebagai tugas akhir secara terstruktur. Proyek ini dibuat khusus untuk mengukur pencapaian akhir peserta melalui pengalaman belajar yang disebut Major Design Experience.

Major Design Experience adalah proses pembelajaran berbasis proyek dimana peserta mengidentifikasi permasalahan nyata, merancang solusi secara sistematis, dan menghasilkan produk akhir yang dapat diimplementasikan. Pengalaman ini menekankan penerapan keterampilan teknis, kreativitas, kolaborasi, serta kemampuan berpikir kritis dan analitis yang telah dipelajari selama mengikuti Program Coding Camp powered by DBS Foundation.

Melalui Capstone Project, peserta ditantang untuk menyelesaikan masalah yang berasal dari permasalahan nyata yang dihadapi industri atau fenomena/kebutuhan di lingkungan sekitar, baik secara individu, komunitas, maupun masyarakat luas. Maka produk akhir dari proyek ini harus dapat menjadi solusi nyata yang relevan dan bermanfaat bagi perusahaan atau masyarakat.

Selama menjalani Capstone Project, peserta akan bekerja secara tim untuk merancang solusi dan menyelesaikan proyek. Peserta akan menerapkan pendekatan engineering design, yang mencakup proses identifikasi masalah, eksplorasi ide, pengembangan prototipe, hingga evaluasi solusi.

Selain menjadi sarana untuk menunjukkan kemampuan, Capstone Project juga menjadi bekal penting bagi peserta untuk mempersiapkan diri menghadapi dunia kerja dan tantangan industri di masa depan.





Peraturan Umum Capstone Project
Tidak ada toleransi untuk plagiarisme
Sebelum mengerjakan proyek capstone Anda, mohon perhatikan beberapa ketentuan berikut:

Peserta wajib membangun proyek dari awal.
Dilarang menyalin penuh repository atau kode dari sumber lain tanpa adanya perubahan/modifikasi.
Peserta boleh merujuk, artinya peserta memahami lalu menulis ulang dan memodifikasi kode yang sudah ada. Berbeda dengan menyalin, yaitu langsung menempel kode tanpa tahu isinya.
Peserta diperbolehkan menggunakan framework, bahasa pemrograman, teknik, tools, atau kode yang pernah dibuat sendiri sebelumnya.
Salah satu yang disarankan adalah dengan mencoba mengimplementasikan ulang solusi dengan gaya/bahasa sendiri, misalnya menulis ulang atau mem-porting dari referensi.
Semua proyek harus dilakukan dengan Kode Etik Coding Camp
Peserta dilarang meminta bantuan dari pihak eksternal untuk proses pengerjaan capstone project. Apabila peserta terindikasi atau terbukti mengerjakan capstone project dengan bantuan pihak eksternal, maka peserta harus siap dengan risiko yang ada termasuk penonaktifan status peserta dan/atau tidak lulus dari program Coding Camp powered by DBS Foundation.

Peserta dapat menggunakan API/Sumber Data/Pustaka publik apa pun
Peserta boleh menggunakan dataset dari Kaggle, Satu Data Indonesia, Google Research Dataset, Google Cloud Public Dataset, atau platform lain yang relevan dengan proyek.
Cantumkan kutipan/sumber dengan benar untuk setiap dataset atau referensi yang digunakan.
Disarankan menggunakan perangkat lunak atau library sumber terbuka.
Semua pekerjaan proyek harus didokumentasikan dengan baik.
Untuk pengumpulan project, tim wajib mengunggah ke GitHub dengan pengaturan private.
Sertakan file README yang lengkap dan komprehensif di GitHub berisi:
Cara instalasi dan penyiapan proyek
Petunjuk penggunaan
Informasi penting lainnya terkait proyek
Sebagai bentuk perlindungan data, jangan mencantumkan detail spesifik yang bersifat rahasia seperti credential/API key/Password/Data Sensitif.

List Tech Stack Capstone Project (Checklist Tugas Wajib dan Opsional)
Dalam pengerjaan capstone project, terdapat 2 jenis checklist (Tech Stack) yang harus dipenuhi oleh tim capstone, diantaranya adalah Main Quest (Wajib) dan Side Quest (Opsional, nilai tambah). Adapun fungsi tech stack adalah sebagai berikut:

Memandu tim melalui checklist checklist tugas wajib dan optional untuk mencapai Minimum Viable Product (MVP).
Membantu tim capstone untuk menyusun pembagian tugas antar anggota tim.
Pengerjaan capstone project menjadi lebih terarah.
Silakan perhatikan Checklist Tech Stack berikut untuk mengetahui lebih lanjut checklist apa saja yang perlu diselesaikan oleh Tim Capstone:


Main Quest (Checklist yang Wajib Terpenuhi)
Definisi: Merupakan checklist wajib yang harus dipenuhi oleh Tim Capstone untuk mencapai Minimum Viable Product.

Tugas: Buatlah sebuah aplikasi yang mengintegrasikan dua teknologi utama: Front-End dan Back-End, untuk memberikan solusi terhadap suatu permasalahan yang sesuai dengan tema yang telah ditentukan.

List Tugas: Front End and Back End
Menggunakan networking calls untuk berinteraksi dengan API pada proyek.
Menggunakan module bundler (seperti webpack, Vite, dan sejenisnya) untuk membangun proyek aplikasi web.
Membangun RESTful API untuk mendukung aplikasi Front-End.
RESTful API dapat menyimpan data dengan atau tanpa menggunakan database.
Membuat RESTful API dengan URL yang mengikuti standar konvensi RESTful.
Mengintegrasikan kemampuan AI/ML sebagai fitur utama aplikasi, baik melalui back-end aplikasi maupun langsung pada perangkat pengguna (browser).
Memastikan implementasi fitur utama yang dikembangkan dalam proyek berjalan dengan baik tanpa menyebabkan aplikasi crash.
Tindakan yang Dilarang:

Menggunakan web generator untuk membuat aplikasi front-end maupun back-end.


List Tugas: Artificial Intelligence
Membangun model Deep Learning menggunakan TensorFlow Functional API atau Model Subclassing, yang disesuaikan dengan dataset dan permasalahan bisnis yang telah ditentukan oleh tim Data Science (jika ada).
Mengimplementasikan setidaknya satu komponen kustom lanjutan dalam proses pengembangan model, seperti:
Custom Layer
Custom Loss Function
Custom Callback
Menyimpan dan mengekspor model yang telah dilatih secara penuh dalam format TensorFlow siap produksi (.keras atau SavedModel).
Membuat kode sederhana untuk proses inference model.
Tindakan yang Dilarang:

❌ Menggunakan model yang sudah tersedia dari TensorFlow Hub atau sumber serupa.

❌ Menggunakan model langsung dari layanan API seperti ChatGPT API, Gemini API, dan sejenisnya.

❌ Menggunakan AutoML untuk membuat model AI diskriminatif (Vertex AI hanya diperbolehkan untuk use case Generative AI).


List Tugas: Data Science
Mengumpulkan dan menganalisis berbagai permasalahan, kemudian menentukan satu solusi utama yang akan dikembangkan dalam proyek.
Mendefinisikan pertanyaan bisnis yang dapat diukur.
Melakukan proses Data Wrangling secara end-to-end, yang mencakup:
Gathering Data: Mengumpulkan data atau mencari dataset yang relevan, baik dari sumber publik maupun melalui proses scraping.
Assessing Data: Mengevaluasi kualitas dan struktur data.
Cleaning Data: Membersihkan dan mempersiapkan data sebelum masuk ke tahap analisis.
Melakukan Exploratory Data Analysis (EDA) untuk mendapatkan insight dari data.
Membuat visualisasi data dan melakukan explanatory analysis untuk menjawab pertanyaan bisnis.
Mengembangkan dashboard interaktif menggunakan Streamlit untuk menampilkan insight dan kesimpulan.
Memastikan data sudah siap diproses oleh model, serta disarankan untuk membuat Data Dictionary.
Tindakan yang Dilarang:

❌ Menggunakan dataset yang sudah siap pakai tanpa melakukan proses pembersihan data secara manual.

❌ Melakukan analisis data tanpa memberikan penjelasan dalam bentuk markdown atau teks.

❌ Menarik kesimpulan tanpa didukung oleh visualisasi data.

❌ Menghasilkan format dataset akhir yang belum siap digunakan pada tahap pemodelan.

❌ Menyertakan informasi target ke dalam fitur training (data leakage).


Side Quest (Checklist Optional, Nilai Tambah)
Tingkatkan kualitas proyek dan dapatkan nilai tambah dengan mengimplementasikan rekomendasi berikut:
Front-End dan Back-End
Membuat mockup aplikasi sebagai representasi visual dari desain dan antarmuka pengguna (UI).
Membangun layout aplikasi web yang responsif agar dapat berjalan dengan baik pada berbagai ukuran layar perangkat.
RESTful API dapat menyimpan data ke dalam database.
RESTful API dibangun menggunakan framework Express.
Rekomendasi tools untuk meningkatkan proses pengembangan aplikasi web: Bootstrap / Tailwind CSS, Axios.
Melakukan deployment aplikasi web ke server.
Rekomendasi layanan hosting: GitHub Pages, Netlify, atau Vercel.

Artificial Intelligence
Mengembangkan REST API mandiri menggunakan FastAPI atau Flask untuk melayani model machine learning.
Mengimplementasikan training dan evaluation loop kustom secara penuh dari awal menggunakan tf.GradientTape.
Menggunakan API Generative AI untuk fitur tambahan atau fitur sekunder pada aplikasi.
Mengintegrasikan TensorBoard untuk memantau dan memvisualisasikan metrik pelatihan secara menyeluruh, serta menyertakan log yang dihasilkan dalam repository akhir.
Memastikan model memiliki performa yang baik, dengan ketentuan minimum:
Akurasi minimal: 85%
MAE maksimal: 0,02

Data Science
Melakukan feature engineering untuk menghasilkan fitur yang lebih informatif bagi model.
Melakukan deployment dashboard ke Streamlit Cloud agar dapat diakses secara publik.
Mengimplementasikan A/B Testing menggunakan Python.
Membuat laporan teknis komprehensif mulai dari tahap Problem Discovery hingga hasil akhir proyek dalam format PDF.

Tahap 1. Pendaftaran Tim Capstone
Pada tahap ini, peserta harus melakukan pendaftaran tim capstone melalui formulir pendaftaran yang telah kami sediakan. Setiap tim dapat mengajukan capstone team secara mandiri dan perlu menentukan anggota serta menentukan use case mana yang dipilih sebagai proyek capstone nya. Tahap ini menjadi langkah awal bagi peserta untuk memulai perjalanan capstone project pada program Coding Camp powered by DBS Foundation.


Silakan daftarkan tim kamu sebelum tanggal 29 Maret 2026 pukul 23.59 WIB, melalui formulir berikut:

Formulir Pendaftaran Tim Capstone

Catatan Penting:

Opsi komposisi tim adalah:
2 Fullstack - 2 Data Science - 1 AI Engineer
2 Fullstack - 2 Data Science - 2 AI Engineer
Pendaftaran tim capstone dapat dilakukan pada periode: 13 - 29 Maret 2026 pukul 23.59 WIB.
Formulir wajib diisi oleh 1 orang perwakilan tim. Jika terjadi double submission, maka submission/pendaftaran pertama yang akan kami validasi.
Dilarang memasukkan/mendaftarkan anggota kelompok tanpa persetujuan mereka. Pelanggaran akan mengakibatkan pengurangan nilai untuk individu yang bertanggung jawab atas pengajuan tersebut, dan status grup dapat diubah menjadi INVALID.
Ingat! Bagi peserta yang tidak mendapatkan kelompok hingga batas waktu yang ditentukan, maka akan dibuatkan tim secara acak (random) oleh Tim Coding Camp sesuai dengan ketersediaan peserta yang ada dengan komposisi tim yang mungkin tidak ideal/tidak sesuai dengan ketentuan yang kami sediakan.
Pembentukan tim capstone secara acak (random) akan disesuaikan pembentukan timnya dengan progress kelas dan jumlah kelas yang telah diselesaikan oleh masing-masing peserta (tentatif, sesuai dengan ketersediaan peserta yang ada).
Setelah proses registrasi selesai, peserta akan mendapatkan email validasi final tim capstone yang didalamnya terdapat informasi ID tim capstone, email Google Group, dan informasi detail anggota. Silakan gunakan email google group untuk mengirimkan pesan email pada seluruh anggota, karena email google group telah mencakup email seluruh anggota tim.
Untuk memudahkan koordinasi dan diskusi antar anggota, peserta diperbolehkan membuat grup Whatsapp dengan masing-masing anggota tim capstone.

Tahap 3. Perencanaan Proyek Capstone
Pengisian Dokumen Pakta Integritas
Pakta Integritas adalah dokumen yang berisi kesepakatan/janji/komitmen mengenai etika pengerjaan proyek, kejujuran akademik, serta kesungguhan dalam menyelesaikan project hingga tahap akhir. Setiap tim wajib menandatangani pakta integritas sebagai bentuk komitmen untuk menjalankan capstone project secara profesional.

Sebelum mengisi dokumen pakta integritas, harap perhatikan beberapa ketentuan berikut ini:

Dokumen Pakta Integritas harus diketahui dan ditandatangani oleh semua anggota tim.
Jika tim capstone ditemukan melakukan kecurangan akademik/melibatkan pihak ketiga dalam menyelesaikan proyeknya/melakukan pelanggaran lainnya, baik yang telah ditentukan maupun di luar peraturan yang telah ditetapkan oleh Tim Coding Camp, maka kami akan menggunakan dokumen ini sebagai dasar hukum untuk memberikan sanksi kepada tim/anggota yang terlibat dalam pelanggaran tersebut.
Silakan gunakan dokumen template Pakta Integritas yang disediakan oleh Tim Coding Camp di sini: Template Pakta Integritas (harus ditandatangani oleh semua anggota tim)
Dokumen Pakta Integritas akan diserahkan bersamaan dengan pengumpulan dokumen project plan.
Penyusunan & Pengumpulan Dokumen Project Plan
Setelah tim mendapatkan informasi komposisi anggota, maka tim capstone harus segera membuat dokumen project plan yang berisi rencana pengembangan proyek yang akan dilakukan bersama tim sesuai dengan tema capstone yang dipilih. Dokumen project plan harus mencakup beberapa bagian perencanaan seperti latar belakang dan tujuan proyek, ruang lingkup, jadwal, sumber daya, serta strategi manajemen risiko yang akan dilaksanakan oleh tim capstone.

Sebelum menyusun dokumen project plan, mohon perhatikan informasi berikut ini:

Silakan gunakan template dokumen project plan berikut: Template Dokumen Project Plan
Format penamaan file: Project Plan - [ID Tim Capstone]
Periode penyusunan dokumen project plan dapat dilakukan pada tanggal 1 - 17 April 2026. Pastikan kamu mengumpulkan dokumen project plan tepat waktu, paling lambat pada tanggal 17 April 2026 sebelum pukul 17.00 WIB.

Review Project Plan oleh Asesor
Setelah seluruh dokumen project plan terkumpul, selanjutnya dokumen project plan akan masuk ke tahap Review oleh Asesor. Asesor merupakan tim profesional yang bertugas untuk mengevaluasi kelayakan dan kesiapan dokumen proyek capstone tim kamu. Review ini mencakup beberapa indikator penilaian sebagaimana yang tercantum pada informasi indikator penilaian di sini.


Pengumuman hasil review dokumen project plan akan disampaikan pada tanggal 24 April 2026.


Berdasarkan hasil review/penilaian Asesor, project tim kamu akan memperoleh salah satu dari 2 (dua) status berikut:

Diterima
Dokumen Project Plan tim kamu telah dinilai layak dan dapat dilanjutkan ke tahap implementasi tanpa adanya catatan tertentu dari Asesor.
Diterima dengan Catatan
Dokumen project plan kamu memerlukan beberapa perbaikan berdasarkan catatan dari Asesor. Dalam hal ini, tim kamu tidak perlu mengirimkan / mengumpulkan dokumen revisi project plan yang baru. Cukup lakukan revisi langsung pada dokumen Project Brief sesuai dengan arahan yang diberikan oleh Asesor. Pastikan seluruh revisi dilakukan dengan jelas dan lengkap untuk mendukung kelancaran proses project tim kamu selanjutnya.
Ketika email pemberitahuan hasil review sudah diterima, harap membaca catatan dari asesor dengan saksama dan segera melakukan perbaikan sesuai dengan catatan Asesor. Perbaikan dilakukan secara langsung pada dokumen project brief tanpa harus mengumpulkannya kembali.


Jika komentar/catatan Asesor atas hasil penilaian tim Anda dirasa kurang jelas, silakan untuk segera menghubungi Tim Coding Camp melalui email untuk melakukan klarifikasi lebih lanjut.

Status 2: Selesai (Terlambat)

Lembar kerja capstone tidak diisi, deskripsinya tidak jelas, dan tidak ada bukti pendukung bahkan hingga jadwal verifikasi selanjutnya.
